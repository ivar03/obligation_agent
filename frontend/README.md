# Continuity Guardian — Frontend

Next.js 15 App Router web application built with TypeScript, Tailwind CSS, Lucide icons, and a typed API client.

## Getting Started

1. Install packages:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Run lint & build:
   ```bash
   npm run lint
   npm run build
   ```
